## Format every story follows
1. Title / Genre / Tone / Difficulty / Playtime / One-line hook
2. Full premise
3. Cast (3–6 characters: age, role, personality, motivation, fear, secret, relationships, wants, hides)
4. Central conflict & hidden truth (GM-only — never shown to players)
5. Chronological timeline (the "real" order of events, distinct from reveal order)
6. Act-by-act event list (18–25 events), each with:
   - Event (what actually happens in-story)
   - What the drawer secretly sees/knows
   - Drawing objective (the core concept to communicate)
   - Key visual elements
   - What NOT to reveal (spoiler guard)
   - Difficulty (Easy/Medium/Hard)
   - Hint (revealed if guessers are stuck)
   - Accepted guess concepts (for semantic matching)
   - Three options (A/B/C) offered to the drawer — only one is canon; the other two are valid same-scene distractors
7. Foreshadowing → payoff map
8. Twist summary
9. Ending + alternate ending
10. Story graph
11. Recurring objects / visual motifs
12. Why it's fun to play

More stories will be added to this library in the same depth. This file will be updated as a running table of contents.
